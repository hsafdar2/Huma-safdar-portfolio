# Student Profile Application

This is a simple Python program for managing student profiles.  
It was created for Homework Assignment 4.

## What the program does

The program allows the user to:

- Add a new student  
- Search for a student by ID  
- Update student information (name, email, or major)  
- Delete a student  
- Display all students  

## How it works

- The program reads data from a file called `studentProfile.txt`
- It stores the data in a dictionary
- All operations are done using that dictionary
- When the program exits, it writes updated data to `studentProfileupdated.txt`

## Files included

- `Huma_Safdar_HA4_application.py` → main program (menu + file handling)  
- `Huma_Safdar_HA4_utility.py` → helper functions (add, search, update, delete, display)  
- `studentProfile.txt` → input file

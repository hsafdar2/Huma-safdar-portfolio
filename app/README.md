# 📱 Mobile Application Project

🔗 https://studio.code.org/projects/applab/2698addd-ab5c-44fa-8ce6-4b8e0e9632fe

## 📌 Description
This project is a mobile application developed using Code.org App Lab. The goal of the project was to design an interactive app with a user-friendly interface and basic functionality.

The app includes multiple screens, navigation features, and user interactions such as buttons and input elements. It demonstrates how logic and event-driven programming can be used to create a working application.

Through this project, I explored how applications are structured and how users interact with digital interfaces.

## 🛠️ Skills Demonstrated
- Basic JavaScript (event-driven programming)  
- UI design and user interaction  
- Multi-screen navigation  
- App development using App Lab

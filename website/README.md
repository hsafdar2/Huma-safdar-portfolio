# 🌐 IT 104 Website Project

🔗https://mason.gmu.edu/~hsafdar2/index.html

## 📌 Description
This project is a multi-page website developed as part of my IT 104 coursework. The goal was to build a functional website using basic HTML while following a structured layout and design format.

The site includes several pages such as a homepage, syllabus page, and references page. Each page is connected through navigation links, allowing users to move between sections easily. The project focuses on proper use of HTML elements including headings, paragraphs, lists, images, and hyperlinks.

In addition, the website was uploaded and hosted using George Mason University’s server, which required working with tools like FileZilla and VPN access. This helped me understand how web files are deployed and managed on a live server.

## 🛠️ Skills Demonstrated
- HTML structure and page layout  
- Multi-page website navigation  
- File organization and linking  
- Web hosting using a remote server

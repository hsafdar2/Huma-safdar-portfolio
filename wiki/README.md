# 📚 AI Wiki / Knowledge Pages

🔗 https://sites.google.com/view/huma-ai-research/home

## 📌 Description
This project is a wiki-style website created using Google Sites to organize information about artificial intelligence topics.

It contains structured pages that explain key concepts, research insights, and topic-based information in a clear and organized format. The goal is to make complex AI topics easier to understand through simple explanations and navigation.

## 🛠️ Skills Demonstrated
- Information organization  
- Research and structured content  
- AI concept explanation  
- Web publishing (Google Sites)
